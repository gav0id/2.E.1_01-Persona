Ejercicio 2.E.1 01 - Persona

Lógica del programa
Para resolverlo, cree una clase principal llamada `Persona` que define dos atributos básicos: `nombre` (tipo String) y `edad` (tipo int). 

Dentro del método `main`, implementé la siguiente lógica:
1. Se instanciaron dos objetos independientes a partir de la clase `Persona` (`persona1` y `persona2`).
2. Se le asignó un estado particular a cada objeto accediendo a sus atributos (Lucía, 21 años y Mateo, 23 años).
3. Se imprimieron los datos de ambos objetos por consola para comprobar que cada instancia guarda su propia información de manera independiente.
